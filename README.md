# vlNavProServer


# 基于视觉语言大模型的无地图自然语言导航系统

## 项目概述

本项目面向室内真实环境，构建了一套基于视觉语言大模型（VLM）的无地图自然语言导航系统。系统以 i5 笔记本作为主控，搭载 RGB-D 摄像头与 2D 激光雷达，驱动 KOBUKI 移动底盘，能够在**无预先建图**的条件下，依据用户自然语言指令完成室内导航任务。

系统支持的典型指令示例：

* 精确指令："出门右转，走到白色垃圾桶旁边。"
* 路径指令："出门进入走廊，右转，沿着走廊走到方程式赛车旁边。"
* 模糊指令："出门进入走廊，沿着走廊走到头，然后左转，走到室外。"
* 回溯指令："返回实验室出发点。"

---

## 系统架构

系统采用多层架构设计，各层职责明确：

**感知层：** RGB-D 摄像头采集彩色图像与深度信息，2D 激光雷达提供周围障碍物距离数据，共同构成环境感知输入。

**决策层（VLM 规划）：** 将历史帧序列输入视觉语言大模型，模型结合当前视觉观测与自然语言指令，输出下一个 waypoint 预测点，作为局部导航目标。

**导航层：** 基于 Nav2 框架的局部规划器执行 waypoint 跟踪，利用 RGB-D 深度信息反解生成局部代价地图，配合 2D 雷达实现实时避障，全程不依赖全局地图。

---

## 核心功能与技术要点

### 1. 无地图导航（Mapless Navigation）

系统无需预先构建全局地图或进行 SLAM 建图，仅依靠实时感知与 VLM 推理完成导航，降低了部署门槛，提升了对未知环境的适应能力。

### 2. 历史记忆增强预测（Historical Enhancement）

向 VLM 输入的不仅是当前帧，而是一段历史帧序列。历史视觉信息为模型提供了运动上下文和环境记忆，有助于提升 waypoint 预测的准确性与连贯性。

### 3. 逻辑地图构建（Logical Map）

系统在导航过程中动态构建逻辑地图，记录已访问区域、关键地标和路径拓扑关系。逻辑地图支撑以下两项关键能力：

* **模糊指令执行：** 当用户指令包含"室外""出发点"等语义模糊的目标描述时，系统通过逻辑地图中的地标关联与拓扑推理，将模糊目标映射为可执行的导航序列。
* **回溯导航：** 支持"返回实验室"等回溯类指令，基于逻辑地图中记录的历史路径实现原路返回或路径规划。

### 4. 探索与纠正机制（Exploration & Correction）

当实际环境与指令预期不匹配时（例如指令要求左转但左侧门关闭），系统具备探索纠正能力：

1. 识别指令中的最终目标（如"走到室外"）；
2. 在决策分支处记忆多个可选方向；
3. 按指令优先执行（左转）；
4. 发现当前路径不可达后，回退至决策分支点；
5. 尝试其他方向，最终完成目标。

该机制使系统在指令与现实不完全匹配的情况下，仍能通过探索性尝试完成导航任务。
